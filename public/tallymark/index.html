How Tallymark works.

Short answers to the things people ask first.

Timing a one-minute sheet

  1. Make a fluency sheet and print the student copy and the teacher copy.
  2. Press Timer and score, then Start. Say go, and the child reads across each row.
  3. When the chime sounds, draw a line after the last letter reached on the teacher copy. Slash each miss.
  4. Type what was reached and how many errors. Correct is reached minus errors. Save it to add it to the chart.

How the weekly scramble works

The week's Monday date decides the order, so the same week always gives the same sheet, and next week gives a new one. Each letter appears equally often, and the same letter never sits next to itself. To make your own, choose My own code and type any words, like Room 12 Unit 3.

Saved setups

Once the format, sets and options are how you like them, type a name under Saved setups and press Save. Press the name any time to bring them back.

Printing tips

  • Choose US Letter or A4 under Printing. Set the print dialog to 100% or Actual size, with no headers and footers.
  • If a browser prints oddly, use Save PDF and print the file.
  • Larger type makes fewer, bigger items per page, which suits early readers.

Your data and backups

Class lists, scores and setups are saved only in this browser. Nothing is uploaded. If you clear your browsing data or switch devices, they will not come with you, so download a backup on the Progress tab now and then. Tallymark reminds you after 30 days.

Using it offline

Open the site once, then use your browser's Install option to add it to your device. After that it works without internet. On an iPhone or iPad, tap Share, then Add to Home Screen.

Privacy. Tallymark stores class lists and scores only on this device. Nothing is sent to a server, and there are no accounts or analytics.
